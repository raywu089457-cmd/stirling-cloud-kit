核心設計

決定為什麼
只綁 127.0.0.1 對外完全不開 port。網路上掃不到，也不會踩到 Docker 繞過 ufw 的老問題。
走 Tailscale 不用買網域、不用弄憑證、不用設帳密。只有你自己 tailnet 裡的裝置進得來。
資料掛在 ./data 容器砍掉重建，設定和資料庫都還在。

需要什麼

唯一符合「真的免費 + 規格夠」的是 Oracle Cloud Always Free： ARM Ampere A1 2 核 / 12 GB RAM、200 GB 磁碟、10 TB 流量。

規格變動提醒 Oracle 在 2026/6/15 悄悄把免費 ARM 從 4核/24GB 砍半成 2核/12GB，沒發公告。 Stirling 只需要 2 GB（建議 4 GB），所以 12 GB 還是綽綽有餘。

安裝步驟

  1. 產生 Tailscale 授權金鑰 到 Tailscale 後台 → Settings → Keys， 產生一把 auth key。建議勾 Reusable 和 Ephemeral，期限 90 天。
  2. 把金鑰填進 cloud-init 打開 cloud-init.yaml，找到這行： 
    tailscale up --authkey=tskey-auth-REPLACE_ME ...
    把 REPLACE_ME 那段換成你自己的金鑰。
  3. 在 Oracle 建 VM 選 Ubuntu 24.04，shape 選 VM.Standard.A1.Flex（2 OCPU / 12 GB）。 展開 Show advanced options → Initialization script， 把整份 cloud-init.yaml 貼進去。
  4. 等 5～10 分鐘 第一次要拉 image。可以之後用 cat /opt/stirling/INSTALL_DONE 確認裝完了沒。
  5. 打開網址 
    http://<VM名稱>.<你的tailnet>.ts.net:8080
    你的裝置要先連上 Tailscale。手機記得把 App 開著。

Oracle 註冊過關技巧

社群回報失敗率很高，這些是真的有用的：

  • 用真實的信用卡或簽帳卡，不要用虛擬卡、預付卡
  • 帳單地址跟卡片登記的完全一致，連標點都一樣
  • 用 Chrome，關掉擋追蹤與廣告阻擋擴充功能，不要開 VPN
  • 用無痕模式重試，一次只註冊一個帳號
過不了怎麼辦 退而求其次：[Hetzner] CAX11（2核/4GB）約 €4/月，或 Vultr / DigitalOcean 約 $5/月。 這份部署包在這些機器上一樣能用，指令完全相同。

常用指令

cd /opt/stirling

sudo docker compose ps        # 看狀態
sudo docker compose logs -f   # 看 log
sudo docker compose restart   # 重啟
sudo docker compose down      # 關掉

# 更新到最新版（設定與資料不會被動到）
sudo docker compose pull && sudo docker compose up -d

# 看 Tailscale 代理設定
sudo tailscale serve status

疑難排解

打開網址連不上

依序檢查這三件事：

  1. 你的裝置有連上 Tailscale 嗎（手機看 App 狀態）
  2. VM 上的服務起來了嗎：sudo docker compose ps 要看到 healthy
  3. 代理設好了嗎：sudo tailscale serve status
tailscale serve 設定失敗

通常是 tailnet 沒開 HTTPS / MagicDNS。到 Tailscale 後台 DNS 頁面開啟 MagicDNS 就好。

真的不行，就用 VM 的 Tailscale IP 直連 http://100.x.x.x:8080。 這種情況要把 compose 裡的 127.0.0.1:8080:8080 改成 8080:8080， 並且務必確認雲端防火牆沒有對外開放 8080。

容器一直重啟 / 記憶體不夠

Stirling 是 Java，吃記憶體，VM 給 4 GB 以上比較保險。 真的只有 2 GB，把 image 換成輕量版 stirling-pdf:latest-ultra-lite（只有基本功能）。

想讓別人也能用

那就不該走 Tailscale 了。改成公開網址 + 打開登入驗證：

ports:
  - "8080:8080"
environment:
  SECURITY_ENABLELOGIN: "true"

然後在雲端防火牆開放 8080，並在 UI 裡設一組強密碼。

安全性

  • 服務本身在 127.0.0.1，只有 VM 自己碰得到
  • 對外連線走 Tailscale 的 WireGuard 加密通道
  • 雲端防火牆只需要開 22 (SSH)
  • 沒有登入驗證是刻意的 —— 因為只有你的 tailnet 進得來
  • 你上傳的 PDF 全程留在這台 VM 上，不會經過任何第三方服務
